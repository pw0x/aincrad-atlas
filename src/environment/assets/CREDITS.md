# Environment assets

The castle, town square and lakeside cabin use [Kloofendal 48d Partly Cloudy (Pure Sky)](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky) from Poly Haven. The sky display uses a locally tone-mapped 2048 × 1024 WebP. A separate 512 × 256 Radiance HDR preserves unclipped sunlight for environment lighting.

The four cumulus silhouettes were baked from procedural three-dimensional density and directional light transmission using the included `bake-clouds.py`. They complement the runtime cloud volume.

The forest combines procedural near branches with photographed needles from [Fir Tree 01](https://polyhaven.com/a/fir_tree_01). The two distant fir atlases contain orthographic views rendered from the original A and B tree meshes. The leafy crowns use clustered photographic sprigs from [Tree Small 02](https://polyhaven.com/a/tree_small_02).

Shoreline boulders and four grass mesh primitives derive from [Rock Moss Set 01](https://polyhaven.com/a/rock_moss_set_01) and [Grass Medium 01](https://polyhaven.com/a/grass_medium_01). Ground textures blend [Leafy Grass](https://polyhaven.com/a/leafy_grass) and [Dry River Pebbles](https://polyhaven.com/a/dry_river_pebbles).

All Poly Haven source assets are [CC0](https://polyhaven.com/license). The terrain, lake, flowers, outer supports, tree placements and cloud distributions are authored for this project.
